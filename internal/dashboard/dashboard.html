Dashboard Guide

🏥 Backend Health

Shows the status of all LLM providers (supercomputer, cloud services, etc.).

  • Green badge (healthy) — Backend is responding and available
  • Red badge (unhealthy) — Backend is down or not responding
  • Primary / FALLBACK — When primary is down, requests automatically use fallback (cloud)
  • Latency (ms) — Response time in milliseconds. High latency may trigger failover

📊 Overview Cards

  • Total Requests — All requests since the proxy started
  • Total Tokens — Combined input + output tokens across all requests
  • Uptime — How long the proxy has been running

📈 Request Rate Chart

Shows requests per minute over the last 10 minutes. Spikes indicate high usage.

📋 Usage by Model

Breaks down requests and tokens by LLM model. Helps identify which models are being used most.

  • Total Req — All-time request count for this model
  • Input Tokens — Tokens sent to the model (what you ask)
  • Output Tokens — Tokens from the model (what it responds)
  • Req/min, Req/hr, Req/day — Recent activity in different time windows

⏱️ Recent Requests

Last 20 API calls made through the proxy.

  • Mode: "stream" vs "sync" — Streaming means the response comes back in chunks; sync waits for the full response
  • Finish — Why the model stopped (e.g., "stop" = completed normally, "length" = hit token limit)
  • User — Who made the request (if tracked)

🚦 Rate Limits

Shows current usage against configured limits. Prevents excessive spending.

  • Requests / minute — How many API calls per minute (green = safe, red = approaching limit)
  • Tokens / minute — Total tokens (input + output) per minute
  • Requests / day, Tokens / day — Daily budgets

If any bar reaches 100%, new requests will be rejected until the window resets.

🔄 Failover & Supercomputer Integration

This proxy connects your supercomputer (primary) to cloud services (fallback):

  • Normal operation: requests use supercomputer (fast, free)
  • Supercomputer down or overloaded → automatically switches to cloud (Fireworks, Bedrock)
  • Look for "FALLBACK" badges in Backend Health to see when this happens

❓ Common Questions

  • Why did it switch to FALLBACK? — Supercomputer was either down, too slow, or queue was full
  • What are input vs output tokens? — Input = your question, Output = the AI's answer. Costs are usually higher for output
  • Should I worry about high latency? — Latency > 5000ms (5 sec) triggers failover. See the config for exact thresholds
  • Why does the dashboard refresh every 5 seconds? — Updates in real-time so you can see what's happening now
